# 備考專案對話紀錄

## 2026-11-20 專案方向與資料夾規劃

### 使用者

我的專案和做歷屆考題有關。因為自己想考順便做題目。這可以做哪些專案以解決那些問題？

### AI

可以把「準備考試時遇到的麻煩」當成專案題目。常見問題與可做的解法：

| 準備考試的問題 | 可以做的專案 |
|---|---|
| 題目散在 PDF、照片或不同網站，不好整理 | **歷屆試題管理系統**：上傳題目、依年份／科目／單元分類、加入標籤與搜尋 |
| 看完答案就忘，錯題也常重複 | **錯題本＋間隔複習**：記錄錯因、安排複習日期，根據答題情況調整複習頻率 |
| 不知道哪些單元最弱 | **考試成績分析器**：記錄每題作答結果，呈現單元正確率、歷年趨勢與待加強項目 |
| 想練習限時作答，但難以模擬考試 | **線上模考工具**：計時、隨機抽題、交卷後看成績與作答紀錄 |
| 題目太多，不知道今天該練什麼 | **每日讀書計畫／題目推薦器**：依剩餘時間、錯題與弱項安排每日任務 |
| 有些題目的解題過程難懂或沒有詳解 | **解題筆記平台**：保存自己的解法、提示與觀念整理，並能連結相關題目 |

**最推薦先做：歷屆試題與錯題分析平台。**

先做一個可用的 MVP：建立題目資料、分類搜尋、記錄作答與錯因，再加上單元正確率統計。這樣既能直接幫助你備考，也能展示資料建模、前後端、搜尋與圖表等能力。

題目是紙本或 PDF 時，也可以後續加上 OCR 匯入；但先從手動新增和整理開始，會比較容易完成。

### 使用者

甚麼是 OCR？

### AI

OCR 是「光學字元辨識」（Optical Character Recognition）。它能從照片、掃描檔或 PDF 中辨認文字，並轉成可搜尋、複製或編輯的文字。

例如，把歷屆考題的頁面拍照後，OCR 可以嘗試讀出題目文字，讓你不用逐題手動輸入。辨識結果可能會有錯，尤其是模糊圖片、數學公式或特殊符號，所以通常還需要檢查修正。

### 使用者

那我要做幾個檔案夾？

### AI

不用一開始建很多，先建 3 個資料夾就夠了：

```text
備考專案檔案夾/
├─ src/              # 專案程式碼
├─ data/
│  ├─ originals/     # 原始考題 PDF 或照片
│  └─ extracted/     # OCR 辨識出的文字
└─ docs/             # 功能與使用說明
```

考題檔案也要留意使用與分享的權限。

## 題目（來源：考卷 PDF 第 8–9 頁）

某保險公司欲建置 AI代理（AI Agent）系統，協助理賠人員處理保單查詢及理賠文件核對等作業。技術團隊規劃導入模型內容協定（Model Context Protocol, MCP），讓 AI Agent能以統一介面存取保單資料庫及文件管理系統；並建立可重複調用的 Skill（AI能力模組），將理賠文件核對等需要 AI語意理解與專業判斷的工作封裝成可重複使用的能力。下列敘述何者正確？

(A) MCP與Skill功能相同，皆負責建立 AI與外部系統間的資料傳輸，因此可互相取代；
(B) MCP負責提供 AI代理統一存取外部工具與資料來源；Skill 則封裝需要 AI語意理解與專業判斷的可重複使用能力；
(C) Skill僅能封裝固定規則的程式流程，不適合處理需要 AI推理或語意理解的工作；
(D) MCP與 Skill每次執行皆必須重新訓練模型，才能完成外部工具存取與任務執行

**官方答案：B（MCP 提供 AI 代理統一存取外部工具與資料來源；Skill 封裝需要 AI 語意理解與專業判斷的可重複使用能力）**

## 1. 場景與關鍵字（上方）

- 場景：保險公司建置理賠 AI Agent：用 **MCP** 統一存取保單資料庫與文件管理系統，再用 **Skill** 把「理賠文件核對」這類需要語意理解與專業判斷的工作封裝成可重用能力；題目問兩者角色差異。
- 關鍵字：MCP（Model Context Protocol）、Anthropic 2024-11 開源協定、MCP Server／Tools／Resources、Agent Skills、SKILL.md、漸進式揭露、可重複使用能力、外部工具存取與程序知識封裝

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A MCP與Skill功能相同，皆負責建立 AI與外部系統間的資料傳輸，因此可互相取代； | ❌ 錯誤 | MCP 是連接 AI 與外部資料／工具的標準協定；Skill 是把工作流程、指令與資源打包成的可重用能力模組，兩者層級不同，不能互相取代。Anthropic 官方 Agent Skills 文件說明 Skill 以 SKILL.md 描述「做什麼、何時用」，由代理依任務匹配時載入。 |
| B MCP負責提供 AI代理統一存取外部工具與資料來源；Skill 則封裝需要 AI語意理解與專業判斷的可重複使用能力； | **最正確** | MCP 以用戶端—伺服器架構提供標準化工具與資料存取；Agent Skills 則把指令、腳本與參考資料封裝成目錄，讓一般代理在任務匹配時變成領域專家。B 精確區分「外部存取介面」與「可重用語意能力」兩件事。 |
| C Skill僅能封裝固定規則的程式流程，不適合處理需要 AI推理或語意理解的工作； | ❌ 錯誤 | Skill 不只是固定規則流程：官方 SKILL.md 本體是逐步指引與範例，可搭配 scripts／references，並由模型依語意判斷何時載入與如何執行；說「不適合 AI 推理」是過度限縮。 |
| D MCP與 Skill每次執行皆必須重新訓練模型，才能完成外部工具存取與任務執行 | ❌ 錯誤 | MCP 呼叫工具、Skill 載入指引都不會重新訓練模型；兩者都是推論期的上下文與工具機制，與模型權重更新無關。 |

## 3. 錯置選項（紅框）與未來選答規則

- A 是**角色混淆**：把協定（連線與工具存取）與能力封裝（程序知識）當成同一件事。
- C 是**能力低估**：把 Skill 限縮成固定規則自動化，忽略其可攜帶指令、腳本與判斷指引。
- D 是**機制誤解**：把推論期工具呼叫誤當成訓練事件。

- 未來選答規則：
  1. 看到「統一介面／連接外部資料庫與工具」→ 想 MCP、工具呼叫、標準協定；
  2. 看到「封裝可重複使用的專業判斷／工作流程」→ 想 Skill、Agent Skills、SKILL.md；
  3. 兩者同時出現時，答案是「互補而非互斥」的選項；
  4. 出現「每次都要重新訓練」「可互相取代」等絕對化敘述，通常是干擾項。

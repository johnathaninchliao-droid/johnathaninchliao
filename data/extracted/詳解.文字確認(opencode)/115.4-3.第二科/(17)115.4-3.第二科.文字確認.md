## 題目（來源：考卷 PDF 第 6 頁）

許多生成式 AI應用平台提供工具（Tools）或工具呼叫（Tool Calling）功能。這些功能主要是為了彌補大型語言模型（LLM）的哪一項先天限制？

(A) LLM本質為機率預測模型，無法直接取得即時資訊、執行高精度數值運算，或呼叫外部工具與系統完成特定任務；
(B) LLM的上下文視窗（Context Window）容量有限，必須透過外部工具來動態增加模型單次可處理的最大 Token上限；
(C) LLM本身無法輸出結構化資料格式（如 JSON），必須仰賴外部工具進行二次轉譯與程式碼排版；
(D) 工具可直接更新模型權重，使模型永久具備新的知識與能力，而無須重新訓練模型

**官方答案：A（LLM本質為機率預測模型，無法直接取得即時資訊、執行高精度數值運算，或呼叫外部工具與系統完成特定任務）**

## 1. 場景與關鍵字（上方）

- 場景：題目問工具呼叫「補的是哪個先天限制」。核心是模型本身只做 token 機率預測，不能自己上網查即時資料、精算或操作外部系統，所以要外接工具。
- 關鍵字：**Tool Calling（工具呼叫）**、**Function Calling**、LLM 先天限制、即時資訊、高精度運算、外部系統、機率預測模型、結構化輸出非主因

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 不能即時取得資訊／精算／呼叫外部系統 | **最正確** | OpenAI 文件開宗明義：function calling（即 tool calling）讓模型連接外部系統與訓練資料以外的資料與動作；Anthropic 也把 augmented LLM 描述為具備檢索、工具與記憶的模型。A 完整對應。 |
| B 上下文視窗容量有限 | ❌ 錯誤 | 工具可間接提供外部資訊，但不會「動態增加模型單次可處理的最大 Token 上限」；視窗是模型架構限制。 |
| C 不能輸出 JSON | ❌ 錯誤 | 現代 LLM 可依 JSON schema 輸出結構化資料；工具呼叫的目的不是幫模型做 JSON 排版，而是連接外部能力。 |
| D 工具可直接更新權重 | ❌ 錯誤 | 呼叫工具不會更新模型權重；這是常見誤解。工具補的能力在推論時使用，不是永久訓練。 |

## 3. 錯置選項（紅框）與未來選答規則

- B 是**混淆容量與能力**：工具不是用來擴充 Token 上限。
- C 是**混淆格式與能力**：JSON 輸出本身已可被支援。
- D 是**混淆推論與訓練**：工具不會改權重。
- 未來選答規則（先問三題）：
  1. 看到「工具／Tool Calling／Function Calling」先想：取得外部即時資料、執行動作、精確計算。
  2. 模型「不知道最新發生什麼」與「算不準」都靠工具補，不是靠加大視窗或改溫度。
  3. 凡說「工具直接更新模型權重」通常錯。

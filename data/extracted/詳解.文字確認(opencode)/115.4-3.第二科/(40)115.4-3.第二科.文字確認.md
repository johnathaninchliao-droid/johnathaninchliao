## 題目（來源：考卷 PDF 第 12–13 頁）

某市政府環保局計劃導入生成式 AI系統，自動分析空氣品質監測報告並產生通知文件。該局每月需處理約 500份監測報告，每份通知約 2,000字。僅考慮AI生成通知文件所輸出的 Token成本，忽略輸入 Token與其他費用。若使用外部 API服務，每 1,000個Token收費0.02美元，且平均每字約需 1.5個 Token。從Token Economics（Token成本估算）的角度評估，下列何者最接近每月的 Token成本？

(A) 每月約需 30美元的 Token成本；
(B) 每月約需 60美元的 Token成本；
(C) 每月約需 90美元的 Token成本；
(D) 每月約需 120美元的 Token成本

**官方答案：A（每月約需 30美元的 Token成本）**

## 1. 場景與關鍵字（上方）

- 場景：每月 500 份報告、每份輸出 2,000 字、每字約 1.5 Token、每 1,000 Token 收 0.02 美元；題目只算輸出 Token 成本，要逐步驗算。
- 關鍵字：Token Economics、輸出 Token 估算、每字 Token 換算、計價單位（每 1,000 Token）、逐步驗算、忽略輸入 Token

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 每月約需 30美元的 Token成本； | **最正確** | 按步驟計算後得到每月約 30 美元，與 A 一致；其餘選項分別差 2、3、4 倍，屬於常見的單位換算錯誤。 |
| B 每月約需 60美元的 Token成本； | ❌ 錯誤 | 60 美元約為正確值的 2 倍，可能來自把每字 Token 誤算為 3，或把 1,000 Token 單位看錯。 |
| C 每月約需 90美元的 Token成本； | ❌ 錯誤 | 90 美元約為正確值的 3 倍，可能來自把每份字數或每字 Token 多乘一次。 |
| D 每月約需 120美元的 Token成本 | ❌ 錯誤 | 120 美元約為正確值的 4 倍，可能來自把報告份數或字數重複計入。 |

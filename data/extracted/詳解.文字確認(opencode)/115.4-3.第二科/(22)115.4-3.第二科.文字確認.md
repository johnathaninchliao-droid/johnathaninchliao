## 題目（來源：考卷 PDF 第 7–8 頁）

某企業導入模型內容協定（Model Context Protocol, MCP）架構，建立一個 AI客服助理。系統中：AI 客戶端負責與使用者互動並決定何時需要外部資訊；MCP Server 提供查詢訂單狀態、取得產品資訊等能力；後端資料庫保存交易資料。下列敘述何者正確？

(A) MCP Server等同於大型語言模型本身，負責生成自然語言回應；
(B) MCP Server負責提供標準化工具與資料存取能力，模型可透過協定呼叫；
(C) 後端資料庫必須直接連接使用者介面，才能符合 MCP架構；
(D) MCP的主要目的在於取代資料庫管理系統

**官方答案：B（MCP Server負責提供標準化工具與資料存取能力，模型可透過協定呼叫）**

## 1. 場景與關鍵字（上方）

- 場景：題幹已把角色分得很清楚：AI 客戶端負責互動與判斷，MCP Server 提供工具／資料存取，資料庫保存資料。問的是你能否守住這個職責分工。
- 關鍵字：**MCP（Model Context Protocol）**、**MCP Server**、標準化工具與資料存取、Client-Server 架構、不是 LLM 本身、不取代資料庫

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A Server 等同 LLM | ❌ 錯誤 | MCP Server 是「提供 context 給客戶端的程式」，不是生成自然語言的模型；生成回應是 LLM／host 的工作。 |
| B Server 提供標準化工具與資料存取 | **最正確** | MCP 官方架構文件指出 MCP server 是提供 context 的程式，並可對外提供工具與資料；intro 更直接說 AI 應用可透過 MCP 連接到資料來源與工具。B 完全吻合。 |
| C 資料庫要直連 UI | ❌ 錯誤 | MCP 是客戶端—伺服器架構，資料庫經由 server 提供，不必也不應直接連到使用者介面。 |
| D MCP 取代 DBMS | ❌ 錯誤 | MCP 是連接標準，目的在於互通，不是取代資料庫管理系統。 |

## 3. 錯置選項（紅框）與未來選答規則

- A 是**角色混淆**：把 Server 當成模型本身。
- C 是**架構誤解**：MCP 正是為了解決直連與多樣整合問題。
- D 是**目的誇大**：協定不取代資料庫。
- 未來選答規則（先問三題）：
  1. 記 MCP 三角色：Host（AI 應用）→ Client（連線）→ Server（提供工具／資料）。
  2. 看到「MCP Server 負責生成回應／取代資料庫／必須直連 UI」通常錯。
  3. MCP 像 AI 應用的 USB-C：統一外接資料與工具，不改寫模型或資料庫。

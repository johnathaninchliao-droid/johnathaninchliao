## 題目（來源：考卷 PDF 第 6 頁）

某開發團隊在使用 AI 程式設計助手開發資料管線系統（Data Pipeline System）時，發現生成的 Python 資料處理套件呼叫方式已是舊版 API，與最新官方文件不符，導致部分功能執行失敗。請問應導入何種技術，使系統能在推理過程中即時存取並導入最新外部文件內容，以確保生成結果符合最新 API 規範？

(A)模型微調（Fine-tuning），將最新文件資料重新訓練進模型權重，讓模型永久記住最新 API；
(B)知識蒸餾（Knowledge Distillation），將大型文件資料庫壓縮為輕量化的專用小型模型；
(C)提示詞快取（Prompt Caching），將常用文件內容快取於提示中，使模型可重複使用既有資訊並降低延遲；
(D)透過 MCP（Model Context Protocol）工具整合，讓模型在推理時即時存取並整合最新的外部文件內容

**官方答案：D（透過 MCP 工具整合，讓模型在推理時即時存取並整合最新外部文件內容）**

## 1. 場景與關鍵字（上方）

- 場景：AI 程式設計助手生成的 Python 資料處理程式呼叫舊版 API；需要讓系統在推理時即時取得最新外部文件，以確保生成內容符合現行規範。
- 關鍵字：**MCP（Model Context Protocol）**、推理時即時存取外部文件、工具整合、微調與知識更新、知識蒸餾、提示詞快取

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 模型微調 | ❌ 錯 | 微調把知識寫入權重，無法因應文件頻繁更新，且成本高、即時性差；題幹要求「推理時即時存取」。 |
| B 知識蒸餾 | ❌ 錯 | 蒸餾是把大模型能力壓縮到小模型，不是即時取得外部最新文件。 |
| C 提示詞快取 | ⚠️ 次優 | 快取可重用既有提示、降低延遲，但內容是「既有」的，無法保證最新；與「即時存取外部文件」不同。 |
| D MCP 工具整合 | **最正確（正解）** | MCP 官方文件說明它讓模型透過工具連接外部資料來源與服務；在推理時取得最新文件正符合需求。 |

## 3. 錯置選項（紅框）與未來選答規則

- A、B 是訓練階段的做法，無法即時反映最新文件；C 是提示最佳化，對象是既有內容。
- **易混淆點**：RAG 也能帶入外部文件，但本題選項寫的是 MCP；MCP 強調以標准化工具介面在推理時連接外部資料與能力，因此 D 最貼題幹「工具整合＋即時存取」。
- 未來選答規則：看到「推理時即時存取／工具整合／標準協定」，聯想 MCP；看到「寫入權重／壓縮模型／快取既有提示」要分辨其更新時效。

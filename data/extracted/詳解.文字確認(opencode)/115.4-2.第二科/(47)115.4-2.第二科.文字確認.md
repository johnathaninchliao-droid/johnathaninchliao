## 題目（來源：考卷 PDF 第 12–13 頁）

某物流公司計劃導入生成式 AI 來預測交通流量並優化配送路線，預期每月處理 500 萬筆路況資料。在進行成本效益評估時，下列何者不屬於 TCO（Total Cost of Ownership）分析中的直接成本考量？

(A) 模型推理過程中 API 呼叫所產生的 Token 使用費用；
(B) 為支援即時路況分析所需的雲端運算與儲存資源成本；
(C) 導入系統後因配送效率提升所帶來的燃油與車輛維運成本下降；
(D) 為模型訓練與優化所投入的 GPU 運算資源與相關基礎設施成本

**官方答案：C（導入系統後因配送效率提升所帶來的燃油與車輛維運成本下降）**

## 1. 場景與關鍵字（上方）

- 場景：物流導入生成式 AI 做路況預測與路線優化，每月 500 萬筆資料；問「不屬於 TCO 直接成本考量」者。
- 關鍵字：**TCO（總持有成本）**、**直接成本 vs 間接成本／效益**、Gartner／IBM 定義、**燃油與維運成本下降是「節省／效益」不是成本**、Token 費用、雲端運算儲存、GPU 基礎設施皆為直接成本。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A API 呼叫的 Token 使用費用 | ❌ 屬直接成本（故非答案） | 推理階段的按量計價支出，可直接歸屬于 AI 系統，屬直接成本。 |
| B 雲端運算與儲存資源成本 | ❌ 屬直接成本（故非答案） | 為支援即時分析所購置的雲端資源，是明確的直接支出。 |
| C 燃油與車輛維運成本下降 | **最正確（不屬直接成本）** | 「成本下降」是導入後的**效益／節省**，不是支出；TCO 分析直接成本是花出去的錢，本項是省下來的錢，故不屬直接成本考量。 |
| D GPU 運算與基礎設施成本 | ❌ 屬直接成本（故非答案） | 訓練與優化所投入的硬體／基礎設施，是直接成本。 |

## 3. 錯置選項（紅框）與未來選答規則

- A、B、D 都是**實際支出**（Token、雲端資源、GPU），屬 TCO 的直接成本。
- C 是**效益而非成本**：「成本下降」在成本效益分析中歸於收益面，不是成本面；這是本題的關鍵陷阱。
- 未來選答規則：
  1. 看到「不屬於 TCO 直接成本」→ 找**不是花錢的項目**，尤其是「成本下降／效率提升／節省」。
  2. TCO 直接成本：可Trace到具體支出的項目（API 費、雲端資源、硬體、人力）。
  3. 間接成本則是難直接歸屬的項目（訓練時間、維護人力、停機損失）；效益則單獨立項。
  4. 注意題目的「直接成本考量」：C 連成本都不是，當然不屬直接成本。

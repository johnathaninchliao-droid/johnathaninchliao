## 題目（來源：考卷 PDF 第 6–7 頁）

某公司開發一個 AI 助理，能長期記住使用者的重要資訊（例如偏好與歷史需求），並在後續對話中加以利用。系統設計採用 Titans 架構的 Memory as Context（MAC）機制，希望模型在回應時能同時參考目前對話與過去記憶。請問在此設計下，長期記憶最可能是下列哪一種使用方式？

(A)將記憶模組整合進模型內部，讓每一層都使用記憶資訊；
(B)利用記憶調整模型的注意力強弱，使部分內容被優先關注；
(C)將記憶整理成重點內容，與目前輸入一起提供給模型作為額外參考；
(D)不使用記憶模組，而是單純增加模型可處理的文字長度

**官方答案：C（將記憶整理成重點內容，與目前輸入一起提供給模型作為額外參考）**

## 1. 場景與關鍵字（上方）

- 場景：AI 助理需長期記住使用者偏好與歷史需求；系統採用 Titans 的 Memory as Context（MAC）機制，同時參考目前對話與過去記憶。
- 關鍵字：**Titans**、**Memory as Context（MAC）**、長期記憶做為上下文、與輸入串接、Memory as Gate（MAG）／Memory as Layer（MAL）對照

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 每層都使用記憶資訊 | ❌ 錯 | 這是 Memory as Layer（MAL）的概念，不是 MAC。 |
| B 用記憶調整注意力強弱 | ❌ 錯 | 這是 Memory as Gate（MAG）的概念（以 gating 結合記憶），不是 MAC。 |
| C 整理成重點與輸入一起提供 | **最正確（正解）** | Titans 論文說明 MAC 的核心分支把長期與持久記憶與輸入序列串接，再交由注意力處理，等同把記憶當成額外上下文。 |
| D 不使用記憶、只增加文字長度 | ❌ 錯 | 單純擴充 context window 不是 MAC，也無法做到「長期記憶」的學習與保存。 |

## 3. 錯置選項（紅框）與未來選答規則

- A、B 分別對應 Titans 的 MAL 與 MAG 變體，是同論文中的其他做法，容易被名稱混淆；D 則完全放棄記憶模組。
- 未來選答規則：看到「Memory as Context／MAC」，聯想「記憶當成上下文與輸入串接」；「as Gate」聯想 gating，「as Layer」聯想逐層整合。

## 題目（來源：考卷 PDF 第 10 頁）

某物流公司部署 Agentic AI 系統，用於自動規劃跨縣市配送排程。當調度員輸入「明天上午前需將高雄倉庫的冷凍物品送達台北三個門市」，系統能自動分解任務、查詢車輛可用性、計算最佳路線並產生排程方案。在此 Agentic 架構中，負責上述任務拆解與決策的核心元件為何？

(A) 任務規劃器（Task Planner）；
(B) 模型訓練器（Model Trainer）；
(C) 工具執行器（Tool Executor）；
(D) API 閘道器（API Gateway）

**官方答案：A（任務規劃器（Task Planner））**

## 1. 場景與關鍵字（上方）

- 場景：物流 Agentic AI 系統，輸入自然語言需求後能「**自動分解任務、查詢可用性、計算路線、產生方案**」；問負責**任務拆解與決策**的核心元件。
- 關鍵字：**任務規劃器（Task Planner／Planner Agent）**、**任務分解（task decomposition）**、DAG／子任務排序、**工具執行器（Tool Executor）負責執行而非規劃**、模型訓練器（訓練階段）、API 閘道器（連線管理）、Agentic 架構元件分工。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 任務規劃器（Task Planner） | **最正確** | Agentic 架構中，planner 負責把目標拆解為子任務、排序依賴並決定要用哪些工具；題幹「自動分解任務、計算路線、產生方案」正是規劃器職責。 |
| B 模型訓練器（Model Trainer） | ❌ 錯誤 | 訓練器屬模型開發／訓練階段元件，與推理時的任務拆解與決策無關。 |
| C 工具執行器（Tool Executor） | ❌ 錯誤 | 執行器負責「實際呼叫工具執行已規劃步驟」，題幹問的是「拆解與決策」，不是執行。 |
| D API 閘道器（API Gateway） | ❌ 錯誤 | 閘道器管理 API 路由、認證與流量，是基礎設施層，不做任務規劃。 |

## 3. 錯置選項（紅框）與未來選答規則

- B 是**階段錯置**：把離線訓練元件當成線上決策元件。
- C 是**角色混淆**：執行器與規劃器是 Agentic 架構中明確分工的兩個角色；題幹問「拆解與決策」，應選規劃器。
- D 是**層級錯置**：API 閘道器屬連線基礎設施，不涉及任務語意。
- 未來選答規則：
  1. 看到「任務拆解／分解／排序／決定先後」→ **Task Planner**。
  2. 看到「實際呼叫工具、執行搜尋或下單」→ Tool Executor。
  3. 看到「訓練／更新模型參數」→ Model Trainer。
  4. 看到「API 路由、認證、限流」→ API Gateway。
  5. 記憶口訣：**規劃想、執行做、訓練學、閘道通**。

## 題目（來源：考卷 PDF 第 9 頁）

某連鎖量販店計劃導入 AI 銷量預測系統，以優化每日進貨與庫存管理。團隊比較兩家軟體廠商提供的迴歸模型，兩個模型皆以相同的測試資料集進行評估，其中廠商甲模型的均方誤差（Mean Squared Error, MSE）為 12.5，廠商乙模型的均方誤差（MSE）為 42.0。僅依據 MSE 指標的數值與定義來評估模型表現，下列何者最適合做為模型評估結果的說明？

(A) 應優先選擇廠商甲的模型，因為其 MSE 較低，代表模型預測值與實際銷量的整體誤差較小；
(B) 應優先選擇廠商乙的模型，因為其 MSE 較高，代表模型能涵蓋更多不同的銷售情境，因此預測能力較佳；
(C) 兩個模型無法直接比較，因為 MSE 主要反映平均預測誤差，無法用來評估不同模型的預測表現；
(D) 由於兩者的 MSE 皆大於 0，代表模型皆存在過擬合（Overfitting）現象，無法判定哪一個模型較佳

**官方答案：A（應優先選擇廠商甲的模型，因為其 MSE 較低，代表模型預測值與實際銷量的整體誤差較小）**

## 1. 場景與關鍵字（上方）

- 場景：連鎖量販 比較兩家廠商的迴歸模型，以**同一測試資料集**評估銷量預測；甲 MSE = 12.5，乙 MSE = 42.0，題目限定「僅依 MSE 數值與定義」判定。
- 關鍵字：**同一測試集**、**均方誤差 MSE**、數值越低越好；對照關鍵字：MSE 越高越好、無法比較、MSE > 0 即過擬合。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 選甲，因 MSE 較低 | **最符合（正解）** | MSE 定義為預測值與真實值差距平方的平均，是典型的誤差損失；同一測試集下 12.5 < 42.0，甲的整體誤差較小。 |
| B 選乙，因 MSE 較高 | ❌ 不符合 | 把誤差指標誤當成「涵蓋情境越多越好」；scikit-learn 明確將 mean_squared_error 歸為 error，越低越好。 |
| C 兩模型無法比較 | ❌ 不符合 | 題目已給「相同測試資料集」，正是可比較的條件；MSE 本來就常用於比較不同迴歸模型。 |
| D MSE > 0 即過擬合 | ❌ 不符合 | MSE 幾乎總是大於零（完美預測才為零），與是否過擬合無必然關係；過擬合須比較訓練與測試表現。 |

## 3. 錯置選項（紅框）與未來選答規則

- B、C、D 分別犯了「誤差方向反讀」「忽略同測試集前提」「把正值門檻當過擬合判據」三種錯誤。
- 未來選答規則：
  1. 看到 MSE、MAE、RMSE 等 `_error`／`_loss` 字眼 → 數值越低越好。
  2. 看到 accuracy、F1、R² 等 `_score` → 數值越高越好；scikit-learn 為統一慣例把 MSE 的包裝成 `neg_mean_squared_error`。
  3. 比較模型的必要前提是相同的評估資料與相同的目標尺度；題目已給此前提就不要選「無法比較」。
  4. 過擬合要看「訓練表現好、測試表現差」的落差，不能只看誤差是否大於零。
- 本題 A 同時滿足「同測試集」與「低 MSE」兩個條件，查無更優解。

| 推論步驟 | 公開依據 |
|---|---|
| 查 MSE 定義 | Wikipedia：MSE 是平均平方誤差，即估計值與真實值差距平方的平均 |
| 查指標方向 | scikit-learn：ending with `_error`／`_loss` 的函數越低越好；MSE 以 `neg_mean_squared_error` 包裝 |
| 逐步驗算一 | 同一測試集：MSE(甲) = 12.5，MSE(乙) = 42.0；12.5 < 42.0 |
| 逐步驗算二 | 差額 42.0 − 12.5 = 29.5；倍數 42.0 ÷ 12.5 = 3.36，乙的平方誤差約為甲的 3.36 倍 |
| 排除 D | Wikipedia 指出 MSE 幾乎總為正值（完美預測才為零），不能據此判定過擬合 |

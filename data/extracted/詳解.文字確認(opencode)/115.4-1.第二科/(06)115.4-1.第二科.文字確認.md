## 題目（來源：考卷 PDF 第 2 頁）

OpenAI 已為 Sora 生成的影片提供多種出處證明機制，以降低誤導性或欺騙性內容帶來的風險。下列何者不屬於目前 OpenAI 官方為 Sora 內容提供的出處證明工具？

(A) 所有資產上內嵌的 C2PA（Content Credentials）元數據；
(B) 預設可見的動態浮水印；
(C) 用於追蹤生成內容的內部反向影像與音訊搜尋工具；
(D) 平台對外開放的實時來源驗證介面

**官方答案：D（平台對外開放的實時來源驗證介面）**

## 1. 場景與關鍵字（上方）

- 場景：OpenAI 為 Sora 生成影片提供多種「出處證明（provenance）」機制，以降低誤導／欺騙風險；問**哪一項不是**官方提供的工具。
- 關鍵字：**C2PA／Content Credentials**、內嵌元數據、可見浮水印（visible watermark by default）、**內部**反向搜尋工具、**對外開放的實時驗證介面（題幹陷阱）**、Sora、OpenAI 官方公告（2024-12-09）。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 所有資產上內嵌的 C2PA 元數據 | ✅ 屬官方提供 | OpenAI《Sora is here》（2024-12-09）：「All Sora-generated videos come with C2PA metadata, which will identify a video as coming from Sora ... and can be used to verify origin.」 |
| B 預設可見的動態浮水印 | ✅ 屬官方提供 | 同文：「we've added safeguards like visible watermarks by default」；屬官方明確列出的保障措施。 |
| C 用於追蹤生成內容的內部反向影像與音訊搜尋工具 | ✅ 屬官方提供（關鍵在「內部」） | 同文：「built an internal search tool that uses technical attributes of generations to help verify if content came from Sora.」題幹以「內部反向影像與音訊搜尋工具」描述此類內部工具；原文用語為「internal search tool using technical attributes」，屬同一類內部驗證機制。 |
| D 平台對外開放的實時來源驗證介面 | **正確答案（不屬於）** | 官方公告列出的是 C2PA 元數據、預設可見浮水印與**內部**搜尋工具，並未宣布對外開放即時來源驗證介面；OpenAI 反而說「未來可能探索與 NGO／研究組織的合作」來壯大 provenance 生態系，可見對外驗證工具尚非官方提供的既有機制。 |

## 3. 錯置選項（紅框）與未來選答規則

- A／B／C 是**反向錯置風險**：題目問「不屬於」，易誤選自己最不熟悉的一項；應逐一對照官方列出的三類工具。
- D 是**「內部」與「對外」錯置**：把內部搜尋工具誤以為已對外開放，或用「即時驗證介面」這種聽起來合理的詞代替官方用語。
- 未來選答規則：
  1. 遇到「不屬於」題，先列出**官方明確列舉的清單**，再逐項比對。
  2. 注意限定詞：**internal／by default／all assets** vs **public／real-time／open interface**。
  3. 涉及 OpenAI 產品功能，以官方公告與官方help center 為準，不憑印象。
- 誠實備註：Sora 產品頁（查核日 2026-11-26）標示「As of April 26, 2026, the Sora product is no longer available」；本題依其 2024 年部署公告的 provenance 機制作判定，屬題目設定的時點。

## 題目（來源：考卷 PDF 第 4 頁）

關於 ChatGPT、Anthropic Claude、GitHub Copilot 等 AI 程式碼輔助工具的運作原理，下列敘述何者正確？

(A) 這些工具基於大型語言模型，經由大量程式碼與文本訓練，透過預測下一個符號來生成程式碼，但不保證產生程式碼的正確性；
(B) GitHub Copilot 會在提供程式碼建議前執行並驗證該程式碼，確保其執行結果正確無誤；
(C) Anthropic Claude 的程式碼建議並非即時生成，而是從事先整理的已知解答資料庫中檢索而得；
(D) ChatGPT 內建完整的編譯器，可在輸出程式碼前自動編譯並更正所有語法與邏輯錯誤

**官方答案：A（基於大型語言模型，預測下一符號生成程式碼，但不保證正確性）**

## 1. 場景與關鍵字（上方）

- 場景：比較 ChatGPT、Claude、Copilot 三類程式碼輔助工具的核心原理，判斷哪一項正確描述「-generation by next-token prediction」與「不保證正確」。
- 關鍵字：**大型語言模型**、大量程式碼與文本訓練、**預測下一個符號（token）**、生成而非檢索、不保證正確性、幻覺／錯誤程式碼、人工審查與測試、編譯器誤植。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A LLM 經大量程式碼與文本訓練，預測下一符號生成程式碼，但不保證正確 | **最正確** | Google DeepMind 官方部落格（2024-05-14）說明 LLM「predict which token most likely follows another, one token at a time」；GitHub 官方文件明確 Copilot 可能產生外觀有效但語意或語法不正確的程式碼，須由使用者驗證。 |
| B Copilot 提供建議前會執行並驗證，確保正確無誤 | ❌ 錯誤 | GitHub 官方 FAQ 指出 Copilot「doesn't test the code it suggests so the code may not always work, or even make sense」；最佳實踐頁要求使用者「always validate the code it suggests」。 |
| C Claude 的程式碼建議從事先整理解答資料庫檢索 | ❌ 錯誤 | Claude 同屬 LLM，採生成式回應而非查表式檢索；查無任何 Anthropic 官方文件支持「預先整理解答庫」之說。此為把生成式模型誤寫成檢索系統。 |
| D ChatGPT 內建完整編譯器，輸出前自動編譯並更正所有語法與邏輯錯誤 | ❌ 錯誤 | LLM 本質是機率生成，不是編譯器；GitHub 官方亦提醒即使語法正確也不代表安全或邏輯正確，仍需人工審查與測試。 |

## 3. 錯置選項（紅框）與未來選答規則

- B 是**驗證誤植**：工具生成建議，不保證執行正確；驗證責任在使用者。
- C 是**生成／檢索錯置**：把 LLM 生成誤寫成答案庫查詢。
- D 是**能力誇大**：把語言模型當成編譯器＋自動除錯器。
- 未來選答規則：
  1. 看到「保證正確／正確無誤／更正所有錯誤」→ 先懷疑，生成式模型不提供這種保證。
  2. 看到「從資料庫檢索已知解答」→ 除非題目明示 RAG／檢索增強，否則是生成式工具錯配。
  3. 看到「內建編譯器／自動測試」→ 與 LLM 的 next-token 生成原理不符。
- 本題唯一符合「生成＋不保證正確」的是 A。

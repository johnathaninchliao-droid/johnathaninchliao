## 題目（來源：考卷 PDF 第 3 頁）

下列何者最能正確說明 Model Context Protocol（MCP）與檢索增強生成（Retrieval-Augmented Generation, RAG）在功能定位上的主要差異？

(A) MCP 主要用於降低模型訓練成本；RAG 主要用於提升推論速度；
(B) MCP 著重模型與外部工具或系統互動；RAG 著重補充模型知識來源；
(C) RAG 必須依賴向量資料庫；MCP 不需任何外部整合；
(D) RAG 屬標準化通訊協議；MCP 屬資料檢索技術

**官方答案：B（MCP 著重模型與外部工具或系統互動；RAG 著重補充模型知識來源）**

## 1. 場景與關鍵字（上方）

- 場景：直接比較兩個常見但未同層級的技術——**MCP（連外部工具／資料源的開放標準）**與**RAG（在用字附近補充知識的檢索生成技術）**，問功能定位主要差異。
- 關鍵字：**Model Context Protocol（MCP）**、Anthropic 開源標準、USB-C 比喻、tools／data sources／workflows、**RAG**、Retrieval-Augmented Generation、Lewis et al. 2020、向量資料庫、通訊協議。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A MCP 降低訓練成本；RAG 提升推論速度 | ❌ 錯誤 | MCP 是連接標準（官方比喻為 AI 應用的 USB-C），與模型訓練成本無關；RAG 的目的是補知識、提升事實性，不是加速推論（反而多一步檢索）。 |
| B MCP 著重模型與外部工具或系統互動；RAG 著重補充模型知識來源 | **最正確** | Anthropic 官方《What is MCP?》：MCP 是 connecting AI applications to external systems 的開源標準，可接資料源、工具與工作流程；RAG 代表論文（Lewis et al., 2020）則把paragraph 檢索與參數化生成結合，用外部知識補足模型。兩者定位正好如 B 所述。 |
| C RAG 必須依賴向量資料庫；MCP 不需任何外部整合 | ❌ 錯誤 | RAG 可用關鍵字／混合檢索，不限向量資料庫；MCP 本身**就是**外部整合標準，「不需任何外部整合」完全說反。 |
| D RAG 屬標準化通訊協議；MCP 屬資料檢索技術 | ❌ 錯誤 | 兩者角色互換：MCP 才是通訊／整合標準，RAG 是檢索增強技術。 |

## 3. 錯置選項（紅框）與未來選答規則

- A 是**目的錯置**：把兩項技術都誤當成效能／成本工具。
- C 是**「必須／不需」絕對化＋反向**：RAG 不必然用向量 DB，MCP 本質就是外部整合。
- D 是**名號互換**：標準協議與檢索技術對調。
- 未來選答規則：
  1. 看到「MCP」→ 想到 **tools／外部系統／開放標準／USB-C 比喻**。
  2. 看到「RAG」→ 想到 **先檢索外部知識再生成／補充模型知識**。
  3. 遇到比較題，先各自寫出「一本質、二目的」，再逐項比對，避免被看似合理的效能詞誤導。

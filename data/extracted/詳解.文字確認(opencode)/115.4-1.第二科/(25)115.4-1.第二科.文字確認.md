## 題目（來源：考卷 PDF 第 6 頁）

某機構計畫導入生成式 AI 旅遊資訊服務對話系統自動生成多語言對話。目前每月需人工翻譯 600 則訊息，每則成本 50 元；若改用 ChatGPT API，每則訊息需 2000 Tokens，而 Token 成本 0.8 元/1000 Tokens，但需額外投入系統整合費用 20 萬元。關於投資報酬率（Return on Investment, ROI）評估，下列何者最為正確？

(A) 每月節省成本 29,040 元，系統整合成本約 7 個月回收；
(B) 每月節省成本 30,000 元，系統整合成本約 7 個月回收；
(C) 每月節省成本 28,040 元，系統整合成本約 8 個月回收；
(D) 每月節省成本 25,000 元，系統整合成本約 8 個月回收

**官方答案：A（每月節省成本 29,040 元，系統整合成本約 7 個月回收）**

## 1. 場景與關鍵字（上方）

- 場景：以 ChatGPT API 取代每月 600 則人工翻譯，評估 ROI 的每月節省額與整合成本回收期。
- 關鍵字：**ROI**、**每月節省成本**、**回收期（payback period）**、人工成本 600×50、Token 成本 2000×600÷1000×0.8、系統整合費用 20 萬、**淨節省＝人工成本－API 成本**、四捨五入約 7 個月。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 每月節省 29,040 元、約 7 個月回收 | **最正確** | 人工 30,000 元－API 960 元＝29,040 元；200,000÷29,040≈6.89 個月≈7 個月。 |
| B 每月節省 30,000 元、約 7 個月回收 | ❌ 錯誤 | 30,000 元只是原人工成本，未扣除 API 費用 960 元，誇大節省額。 |
| C 每月節省 28,040 元、約 8 個月回收 | ❌ 錯誤 | 節省額與回收月數皆不符逐步驗算結果。 |
| D 每月節省 25,000 元、約 8 個月回收 | ❌ 錯誤 | 數字無對應的計算路徑。 |

## 3. 錯置選項（紅框）與未來選答規則

- B 是**忽略新成本**：只算被取代的人工成本，忘記 API 也要花錢。
- C／D 是**算式錯誤**：節省額與回收期皆對不上。
- 未來選答規則：
  1. 先算「原成本」（人工）；
  2. 再算「新成本」（API：則數×每則 Token÷1000×單價）；
  3. 每月節省＝原成本－新成本；
  4. 回收期＝一次性投入÷每月節省，四捨五入。
- 本題逐步驗算結果與 A 完全一致。

## 7. AI 搜尋推論（考驗搜尋能力）

**搜尋所得答案：A（每月節省成本 29,040 元，系統整合成本約 7 個月回收）**

### 逐步驗算（本題關鍵）

| 推論步驟 | 算式 | 公開依據／說明 |
|---|---|---|
| 1. 原人工成本 | 600 則 × 50 元/則 = **30,000 元/月** | 題幹給定；屬「被取代的原有成本」 |
| 2. 每月 API Token 總量 | 600 則 × 2,000 Tokens/則 = **1,200,000 Tokens/月** | 題幹給定 |
| 3. 每月 API 成本 | 1,200,000 ÷ 1,000 × 0.8 元 = 1,200 × 0.8 = **960 元/月** | Token 以每 1,000 Tokens 計價；Wiz／OpenAI 定價說明 token 為計費單位 |
| 4. 每月淨節省 | 30,000 − 960 = **29,040 元/月** | ROI 定義中的 net benefit（ Investopedia ） |
| 5. 回收期 | 200,000 ÷ 29,040 ≈ **6.8865 個月** → 約 **6.9 ≈ 7 個月** | Investopedia payback period＝初始投資÷期間現金流入 |
| 6. 對照選項 | 29,040 元、約 7 個月 → **A** | 與官方答案一致 |

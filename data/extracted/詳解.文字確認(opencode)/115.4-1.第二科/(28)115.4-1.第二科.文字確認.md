## 題目（來源：考卷 PDF 第 6 頁）

某市政府交通局計劃導入生成式 AI 技術來自動生成公車到站時間預測的文字報告，每日需處理約 50 萬筆交通資料並生成 1000 份報告。在評估導入成本時，團隊希望進行 Token Economics 分析（指模型推理與生成過程中，Token 使用量及其費用）。下列何者不屬於 Token Economics 的考量範圍？

(A) 每次 API 呼叫所需的輸入 Token 數量；
(B) 生成報告內容所消耗的輸出 Token 費用；
(C) AI 模型訓練階段使用 Token 數量所需的 GPU 記憶體成本；
(D) 模型推理過程中的 Token 使用量統計

**官方答案：C（AI 模型訓練階段使用 Token 數量所需的 GPU 記憶體成本）**

## 1. 場景與關鍵字（上方）

- 場景：交通局評估生成式 AI 報告成本，題幹**明確定義** Token Economics 為「模型推理與生成過程中 Token 使用量及其費用」，問哪一項不屬此範圍。
- 關鍵字：**Token Economics**、**推理與生成階段**、輸入 Token、輸出 Token、Token 使用量統計、**訓練階段 GPU 記憶體成本**、API 計價、_training vs. inference_、範圍界定。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 每次 API 呼叫的輸入 Token 數量 | ✅ 屬於範圍（非答案） | Wiz（AI tokenomics）說明計費包含 input（prompt）tokens；nOps 公式為 input tokens × input rate + output tokens × output rate。 |
| B 生成報告的輸出 Token 費用 | ✅ 屬於範圍（非答案） | 同上；輸出 token 因逐步生成通常單價更高，正是 Token Economics 核心。 |
| C 訓練階段 Token 所需的 GPU 記憶體成本 | **不屬於範圍（答案）** | 題幹已限定為推理／生成過程；Wiz 明確指出「Tokens are the meter for inference」，而訓練與微調的 compute／硬體成本屬整體 AI 成本（AI cost／TCO），不是以 token 計費的推理帳單。 |
| D 推理過程的 Token 使用量統計 | ✅ 屬於範圍（非答案） | Wiz／nOps 都要求追蹤 token 用量與歸屬，做為成本控制基礎。 |

## 3. 錯置選項（紅框）與未來選答規則

- A／B／D 都是推理計價要素，題目問「不屬於」，容易誤選。
- C 是**階段錯置**：訓練 GPU 成本重要，但屬於 TCO／AI cost，不是本題定義的 Token Economics。
- 未來選答規則：
  1. 先讀題幹定義（inference & generation），不要用外部印象改範圍。
  2. 看到「input token／output token／token 用量統計」＝ Token Economics。
  3. 看到「訓練／微調 GPU、模型Artifacts儲存、向量庫」＝其他成本類別，不屬推理 token 帳單。
- 本題唯一不屬範圍的是 C。

## 題目（來源：考卷 PDF 第 6 頁）

某紡織公司希望建立自動化品質檢測流程，既有的 AI 系統檢測到布料瑕疵時，需自動拍照存檔、發送通知給品管人員。該公司具有一定開發人力，希望快速建置此工作流程，並保有彈性調整空間，下列哪一種解決方案最適合？

(A) 使用 n8n 建立工作流（Workflow），整合 AI 檢測 API、檔案系統、通訊軟體；
(B) 委外開發客製化程式，完全符合公司需求規格；
(C) 採購現成的品質管理軟體，直接導入使用；
(D) 使用 Excel 巨集搭配人工作業處理檢測結果

**官方答案：A（使用 n8n 建立工作流（Workflow），整合 AI 檢測 API、檔案系統、通訊軟體）**

## 1. 場景與關鍵字（上方）

- 場景：布料瑕疵 detection 後要自動「拍照存檔＋通知品管」，公司有開發人力、要快速建置且保留調整彈性。
- 關鍵字：**n8n**、**工作流自動化（workflow automation）**、**AI 檢測 API**、檔案系統、**通訊軟體通知**、節點串接、fair-code、快速建置、彈性調整、_customization_。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A n8n 工作流整合 API／檔案／通訊 | **最正確** | n8n 官方文件定位為 fair-code 工作流程自動化工具，結合 AI 功能與業務流程自動化，提供節點、流程邏輯與大量整合（HTTP Request、檔案、Discord／Slack 等），恰好串接「檢測 API→存檔→通知」。 |
| B 委外客製化程式 | ❌ 錯誤 | 公司已有開發人力且要求快速建置；委外成本高、迭代慢，與「保有彈性調整」衝突。 |
| C 採購現成品管軟體直接導入 | ❌ 錯誤 | 現成軟體不易彈性串接自有 AI 檢測 API 與自訂通知邏輯；題目強調快速且可調整的工作流。 |
| D Excel 巨集＋人工作業 | ❌ 錯誤 | 依賴人工、自動化程度低，且難以穩定整合 API 與即時通知。 |

## 3. 錯置選項（紅框）與未來選答規則

- B 是**成本／速度錯置**：有開發人力就不需要委外。
- C 是**彈性不足**：套裝軟體難以配合自有 API 串接。
- D 是**自動化不足**：Excel 巨集＋人工不符需求。
- 未來選答規則：
  1. 看到「跨系統串接（API＋檔案＋通知）＋快速建置＋可調整」→ 工作流工具（n8n）。
  2. 看到「完全客製、委外」→ 通常較慢較貴，非快速首選。
  3. 看到「人工作業」→ 與自動化需求矛盾。
- 本題唯一滿足「串接＋快速＋彈性」的是 A。

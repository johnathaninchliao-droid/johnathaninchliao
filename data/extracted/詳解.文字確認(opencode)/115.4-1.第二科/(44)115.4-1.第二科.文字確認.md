## 題目（來源：考卷 PDF 第 10 頁）

某智慧製造廠導入語音互動 AI 助理，作業人員可透過語音查詢設備狀態與操作指引。系統流程包含語音轉文字、語言模型生成回覆，以及即時查詢內部系統資料。測試結果顯示：語音轉文字在專業設備術語上錯誤率偏高；語言模型回覆偶有內容不夠精準；系統整體回應速度略慢但仍在可接受範圍。若專案目標為優先確保正確執行指令，下列改進措施的執行順序何者最合理？

(A) 優化語言模型 → 強化語音模型 → 優化系統效能 → 調整生成參數；
(B) 強化語音模型 → 優化語言模型與知識補充 → 調整生成參數 → 優化系統效能；
(C) 優化系統效能 → 強化語音模型 → 優化語言模型與知識補充 → 調整生成參數；
(D) 強化語音模型 → 優化系統效能 → 優化語言模型與知識補充 → 調整生成參數

**官方答案：B（強化語音模型 → 優化語言模型與知識補充 → 調整生成參數 → 優化系統效能）**

## 1. 場景與關鍵字（上方）

- 場景：語音互動助理管線為「語音轉文字（ASR）→ 語言模型生成 → 內部系統即時查詢」；測試顯示三類問題：專業設備術語 ASR 錯誤率高、LM 回覆不夠精準、速度略慢但可接受；目標是**優先確保正確執行指令**。
- 關鍵字：**錯誤率偏高的前端（語音辨識）**、領域術語、模型適應（model adaptation）、知識補充、生成參數、系統效能、優先順序、可接受延遲、正確性優先。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 先優化語言模型再強化語音模型 | ❌ 錯誤 | ASR 是管線入口，術語辨錯會讓後端拿到錯誤指令；Google Cloud 與 Microsoft 官方文件都指出領域專有名詞可用 model adaptation／Custom Speech 改善。源頭未修就先調 LM，不符合「正確執行」。 |
| B 強化語音模型 → 優化語言模型與知識補充 → 調整生成參數 → 優化系統效能 | **最正確** | 依「對正確性的影響程度」排序：先修入口辨識（WER 高）→ 再補模型與知識（回覆不精準）→ 再調生成參數（一致性）→ 最後才處理效能，因題目明說速度「略慢但仍在可接受範圍」。 |
| C 先優化系統效能 | ❌ 錯誤 | 速度已可接受，不是主要瓶頸；把效能排在正確性修正之前，與「優先確保正確執行指令」衝突。 |
| D 強化語音模型後接著優化系統效能 | ❌ 錯誤 | 前兩步方向對，但把效能插在 LM／知識補充與生成參數之前；在延遲可接受的前提下，應先完成內容正確性相關修正。 |

## 3. 錯置選項（紅框）與未來選答規則

- A 是**順序錯置**：忽略管線前端錯誤會向下游傳播。
- C 是**優先順序錯置**：把「可接受」的慢當成首要問題。
- D 是**插入位置錯置**：正確性尚未修完就先做效能。
- 未來選答規則：
  1. **畫出資料流管線**，從最上游開始找「會讓後面全錯」的瓶頸（此題為 ASR 術語）。
  2. **讀題目的目標與限制**：目標是正確性，且延遲已可接受 → 效能排最後。
  3. 排序口訣：**入口辨識 → 內容正確（模型＋知識）→ 輸出穩定（生成參數）→ 效能**。
- 本題唯一同時滿足「先修源頭」與「效能最後」的是 B。

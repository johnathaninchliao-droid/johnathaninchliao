## 題目（來源：考卷 PDF 第 1 頁）

某物流公司正在規劃導入 AI 系統以優化多項業務流程，包含異常包裹偵測、路線自動規劃與倉儲揀貨效率提升。技術團隊在評估過程中，針對不同任務的資料特性與學習目標，討論應採用哪種機器學習方式。請問下列對於各學習方式的敘述，何者有誤？

(A) 監督式學習（Supervised Learning）適合用於異常包裹偵測，前提是須備有大量已標註為正常或異常的歷史資料；
(B) 非監督式學習可（Unsupervised Learning）用於分析倉儲揀貨動線的潛在分群，但無法直接預測特定行為的對錯；
(C) 強化學習（Reinforcement Learning）適合應用於路線規劃，模型透過反覆嘗試與環境回饋，逐步找出最佳配送策略；
(D) 非監督式學習（Unsupervised Learning）可用於異常包裹偵測，並能在缺乏標註資料的情況下，準確判斷每筆資料是否屬於特定異常類別

**官方答案：D（非監督式學習可用於異常包裹偵測，並能在缺乏標註資料的情況下，準確判斷每筆資料是否屬於特定異常類別）**

## 1. 場景與關鍵字（上方）

- 場景：物流公司在異常包裹偵測、路線規劃、倉儲揀貨三個任務上評估監督式／非監督式／強化學習，題目問「何者有誤」。
- 關鍵字：**監督式學習（有標註）**、**非監督式學習（無標註、分群）**、**強化學習（環境回饋、反覆嘗試）**、異常偵測、分群（clustering）、**異常分數（anomaly score）與閾值**、「何者有誤」。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 監督式學習搭配大量標註 | ✅ 敘述正確 | Wikipedia：supervised learning 以 labeled data 訓練，用於 classification 與 regression；有「正常／異常」標註時，異常偵測可視為監督式二元分類（anomaly detection 條目亦列 supervised anomaly detection）。 |
| B 非監督式學習做分群、不直接判斷對錯 | ✅ 敘述正確 | Wikipedia：unsupervised learning 從 unlabeled data 學習 pattern，典型任務為 clustering；cluster analysis 只找共同性，不提供「對／錯」的監督訊號。 |
| C 強化學習做路線規劃 | ✅ 敘述正確 | Wikipedia：reinforcement learning 讓 agent 在動態環境中采取行動以最大化 reward；反覆嘗試與環境回饋正適合找出最佳配送策略。 |
| D 無標註也能「準確判斷屬於特定異常類別」 | **有誤（正解）** | 非監督式異常偵測假設資料未標註，輸出的是**異常分數／偏離程度**，需再設閾值，且沒有「特定異常類別」的標籤可供對照；Wikipedia 明言 supervised 方法才需要「normal／abnormal」標註，unsupervised 方法因標註稀缺而最常用，但並不能「準確判斷屬於特定類別」。「準確判斷特定異常類別」是監督式分類的說法。 |

## 3. 錯置選項（紅框）與未來選答規則

- A、B、C 都精準描述三種學習典範的資料條件與能力；D 把「無標註也能找出離群點」誇大成「能準確判定特定異常類別」，是典型的能力過度宣稱。
- 未來選答規則：
  1. 看到「有大量已標註正常／異常」→ 監督式分類；看到「未標註、找分群／離群」→ 非監督式。
  2. 非監督式異常偵測的正確說法是「找出偏離正常分布的樣本／給出異常分數」，**不是**「判定所屬異常類別」。
  3. 看到「反覆嘗試、環境回饋、最大化獎勵」→ 強化學習。
  4. 遇到「何者有誤」，特別留意吸收了另一種方法能力的選項。
- 本題唯一敘述有誤者為 D。

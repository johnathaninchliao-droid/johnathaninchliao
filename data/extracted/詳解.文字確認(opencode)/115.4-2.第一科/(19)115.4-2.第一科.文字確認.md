## 題目（來源：考卷 PDF 第 5 頁）

某溫室農場開發 AI 系統自動識別作物葉片上的害蟲種類，測試結果顯示：在 1000 張測試影像中，系統正確識別出 80 隻害蟲，但誤判了 20 張正常葉片為有害蟲，同時漏檢了 10 隻實際存在的害蟲。對於害蟲檢測這個關鍵任務，下列哪個評估指標最需要優先關注？

(A) 召回率（Recall）；
(B) 精確率（Precision）；
(C) 準確率（Accuracy）；
(D) F1 分數（F1-Score）

**官方答案：A（召回率（Recall））**

## 1. 場景與關鍵字（上方）

- 場景：溫室害蟲檢測，題幹特意給出「誤判 20 張正常葉片（假陽性）」與「**漏檢 10 隻實際害蟲（假陰性）**」兩類錯誤，並問「關鍵任務」下**最需要優先關注**的指標。
- 關鍵字：**召回率／敏感度（Recall／sensitivity）**、**漏檢（false negative）代價高**、精確率（false positive）、準確率、F1 分數、TP＝80、FP＝20、FN＝10、害蟲防治「寧可多報、不可漏報」。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 召回率 Recall | **最符合（正解）** | Wikipedia 定義 Recall（又稱 sensitivity）為「所有相關實例中被成功檢出的比例」，即 TP/(TP+FN)；scikit-learn 也說 recall 是「找出所有正樣本的能力」。害蟲防治若漏檢，蟲害會擴散，故關鍵任務應優先壓低假陰性、提高 Recall。本題 TP=80、FN=10，Recall = 80/(80+10) = 80/90 ≈ 88.9%。 |
| B 精確率 Precision | ❌ 次優 | Precision = TP/(TP+FP) = 80/(80+20) = 80%，衡量「報出來的是否真的有害蟲」。較高 Precision 代表誤判少，但題幹強調的是「漏檢」風險；若只追求 Precision，系統傾向保守不報，反而增加漏檢。 |
| C 準確率 Accuracy | ❌ 不符合 | Accuracy = (TP+TN)/全部樣本，會被大量正常葉片主導。本題 1000 張影像中多數為正常葉片，即使漏掉全部害蟲，Accuracy 仍可能很高，因此不適合作為關鍵任務的首選指標。 |
| D F1 分數 | ❌ 不符合 | F1 是 Precision 與 Recall 的調和平均，兩者權重相同；本題明確要求「最需要優先關注」單一指標，且任務代價偏重漏檢，故不選兼顧型指標。本題 F1 = 2×0.80×0.8889/(0.80+0.8889) ≈ 84.2%，低於 Recall。 |

## 3. 錯置選項（紅框）與未來選答規則

- B、C、D 都不是「錯誤指標」，而是**優先順序判斷錯誤**：B 管誤報、C 被樣本不平衡稀釋、D 平等對待兩類錯誤；題幹的「關鍵任務」「漏檢」才是排序依據。
- 未來選答規則：
  1. 先問「哪種錯誤代價較高？」：漏掉病蟲／腫瘤／詐騙 → 顧 **Recall**；誤報造成不必要的介入處置 → 顧 **Precision**。
  2. 看到「不平衡資料＋絕大多數為負樣本」→ 不要直接用 Accuracy。
  3. 題目若說「兼顧兩者」「平衡」→ 才選 F1；若說「優先」「最需要關注」→ 選代價較高的那一邊。
  4. 本題明確給出漏檢 10 隻，且任務是害蟲防治，故 Recall 優先。

## 7. AI 搜尋推論（考驗搜尋能力）

**搜尋所得答案：A（召回率（Recall））**

| 推論步驟 | 公開依據與逐步驗算 |
|---|---|
| 由題幹取出混淆矩陣要素 | TP（正確識別害蟲）＝80；FP（正常葉片誤判為有害蟲）＝20；FN（漏檢害蟲）＝10 |
| 計算 Recall | Recall = TP/(TP+FN) = 80/(80+10) = 80/90 = 0.8889 ≈ **88.9%** |
| 計算 Precision（對照） | Precision = TP/(TP+FP) = 80/(80+20) = 80/100 = **80%** |
| 計算 F1（對照） | F1 = 2PR/(P+R) = 2×0.80×0.8889/(0.80+0.8889) = 1.4222/1.6889 ≈ **84.2%** |
| 檢視 Accuracy 的可行性 | 若簡化假設「一張影像對應一隻害蟲或一片正常葉片」，實際正樣本 90、實際負樣本 910，TN = 910−20 = 890，Accuracy = (80+890)/1000 = 97%。但題幹混用「隻」與「張」單位，此 97% 僅為示意，**不作為選答依據**；可確定的是多數樣本為正常葉片，Accuracy 會被稀釋。 |
| 依任務代價排序 | Wikipedia 指出完美 recall 即無 false negative；害蟲漏檢會讓防治延誤，故優先提高 Recall |
| 結論：A | 與公開定義及題幹關鍵字「漏檢」「關鍵任務」一致，查無更優解 |

## 題目（來源：考卷 PDF 第 4 頁）

關於敘述性統計指標，下列敘述何者最為正確？

(A) 中位數（Median）能有效反映極端值對資料分佈的影響；
(B) 標準差（Standard Deviation）越大，代表資料越集中；
(C) 百分位數（Percentile）主要用於衡量資料在整體分布中的相對位置；
(D) 平均值（Mean）適合描述偏態且包含離群值（Outliers）的資料

**官方答案：C（百分位數（Percentile）主要用於衡量資料在整體分布中的相對位置）**

## 1. 場景與關鍵字（上方）

- 場景：四個關於敘述性統計指標的敘述，選出最正確者。
- 關鍵字：**敘述性統計**、中位數、標準差、**百分位數（相對位置）**、平均值、偏態、離群值（outliers）、極端值。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 中位數能有效反映極端值影響 | ❌ 錯誤 | 中位數是「抵抗性（resistant）」統計量，以排名為基礎，極端值幾乎不影響它；NIST 明確說 extreme values do not distort the median。 |
| B 標準差越大代表資料越集中 | ❌ 錯誤 | 標準差衡量離散程度；越大代表資料越分散、越不集中（NIST Measures of Scale 定義）。 |
| C 百分位數衡量資料在整體分布的相對位置 | **最正確（正解）** | NIST 7.2.6.2：第 p 百分位數是「至多 p% 觀測小於它、至多 1−p 大於它」的值，正是描述相對位置；第 50 百分位即中位數。 |
| D 平均值適合描述偏態且含離群值資料 | ❌ 錯誤 | 平均值受極端值扭曲；NIST 指出對有極端值的資料，中位數比平均值更能代表位置，偏態資料宜用中位數／IQR。 |

## 3. 錯置選項（紅框）與未來選答規則

- A 把「抵抗極端值」說成「反映極端值」；B 把「越分散」說成「越集中」；D 把「不適合偏態」說成「適合」。三者都是方向顛倒。
- 未來選答規則：
  1. 中位數／IQR → 抵抗極端值、適合偏態；平均值／標準差 → 易受極端值影響、適合對稱分佈。
  2. 標準差越大 → 越分散；越小 → 越集中。
  3. 百分位數 → 相對位置（第 50 百分位 = 中位數）。
- 本題唯一方向正確的是 C。

**搜尋所得答案：C（百分位數（Percentile）主要用於衡量資料在整體分布中的相對位置）**

| 推論步驟 | 公開依據 |
|---|---|
| 查 NIST Percentiles 定義 | 第 p 百分位描述有多少比例資料低於／高於該值 → 相對位置 |
| 查 NIST Measures of Location | 極端值扭曲 mean，不扭曲 median（因 median 以 rank 為基礎） |
| 查 NIST Measures of Scale | 標準差越大代表越分散，不是越集中 |
| 判定 A | 中位數抵抗極端值，不是反映極端值 → 錯 |
| 判定 B | 標準差越大越分散 → 錯 |
| 判定 C | 百分位數＝相對位置 → 正確 |
| 判定 D | 偏態＋離群值宜用中位數，非平均值 → 錯 |
| 結論：C 最正確 | 交叉比對，查無更優解 |

## 1. 場景與關鍵字（上方）

- 場景：以求「不符合」的負向設問，檢驗考生是否把「有無標籤」當成監督式／非監督式的唯一判準。
- 關鍵字：**非監督式學習**、自動分群（clustering）、不仰賴標籤、探索潛在結構／隱含模式、**輸入特徵與既定目標標記的對應關係（監督式）**、「不符合」。

## 2. 逐項判定（綠框依據）

| 選項 | 判定 | 理由 |
|---|---|---|
| A 依特徵相似性自動分群 | ✅ 符合非監督式 | NIST CSRC 定義 unsupervised learning 從 unlabeled data 中找出結構（如 cluster/group data points）；scikit-learn clustering 即為典型。 |
| B 不仰賴事先定義標籤 | ✅ 符合非監督式 | NIST／Google Cloud 均強調非監督式不使用 pre-defined labels，這是核心判準。 |
| C 探索潛在結構或隱含模式 | ✅ 符合非監督式 | Google Cloud 與 NIST 均列出探索 hidden patterns／structure 為非監督式的主要用途（如 PCA、關聯規則）。 |
| D 學習輸入特徵與既定目標標記的對應 | **不符合（正解）** | 「既定目標標記（label）」＋「輸入→輸出的對應」正是**監督式學習**的定義（NIST CSRC：learns to predict explicit labels）；題目問「不符合」，故 D 正解。 |

## 3. 錯置選項（紅框）與未來選答規則

- A/B/C 都是非監督式教科書式描述，容易被誤以為「不符合」；D 才是被錯配的監督式定義。
- 未來選答規則：
  1. 先問「有沒有既定標記（label）」：有 → 監督式；沒有 → 非監督式。
  2. 出現「分群、相似性、潛在結構、維度縮減」→ 非監督式。
  3. 出現「輸入→既定目標的對應／預測標籤」→ 監督式。
  4. 遇到「不符合」題，逐項貼「監督／非監督」標籤，取標籤不同者。
- 本題唯一貼「監督式」標籤的是 D。
